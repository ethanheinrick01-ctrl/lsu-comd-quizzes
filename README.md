# Study Quiz Hub

Interactive study tools for communication sciences and disorders, acoustics, audiology, and language learning.

**[Open the study hub](https://ethanheinrick01-ctrl.github.io/lsu-comd-quizzes/)**

The latest addition is the **COMD 4590 Aural Rehabilitation: Disorders & Hearing Loss drill**, with a disorder atlas and adaptive retrieval practice.

Open `index.html` locally or use the hosted hub. The core quizzes run in the browser without an account or per-attempt charges. Independent student project; not an official LSU assessment resource.
